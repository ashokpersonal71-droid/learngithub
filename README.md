
# Investment Analysis and Portfolio Management Using R

## Overview

This repository provides R programs, datasets,
numerical examples, and learning resources for
Investment Analysis and Portfolio Management.

The project is designed for MBA students,
faculty members, and finance researchers.

## Learning Objectives

Students will learn to:

1. Calculate financial asset returns.
2. Measure investment risk.
3. Analyze portfolio diversification.
4. Apply the Capital Asset Pricing Model.
5. Explore financial data using R.
6. Develop interactive R Shiny applications.

## Repository Structure

- `R/` - R scripts and financial models
- `data/` - Teaching datasets and documentation
- `shiny/` - Interactive applications
- `figures/` - Charts and visualizations
- `docs/` - Exercises and teaching notes

## Getting Started

1. Download the repository using Code > Download ZIP.
2. Extract the files on your computer.
3. Install R and any required packages.
4. Open an R script in RStudio.
5. Run the script and interpret the results.

## Example: CAPM

The Capital Asset Pricing Model is:

E(Ri) = Rf + beta * (E(Rm) - Rf)

An example is available in `R/capm.R`.

## Data

Teaching datasets are located in `data/`.
Check the data dictionary for variable definitions.
