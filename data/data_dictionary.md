
# Data Dictionary

## Dataset: sample_prices.csv

### Purpose
Illustrative dataset for teaching stock returns,
volatility, and portfolio analysis.

### Variables

| Variable | Description | Unit |
|---|---|---|
| Date | Observation date | YYYY-MM-DD |
| Stock_A | Synthetic price of Asset A | Index units |
| Stock_B | Synthetic price of Asset B | Index units |

### Frequency
One observation per illustrative period.

### Source
Synthetic data created for educational purposes.

### Important Notes
- These are not actual market observations.
- Prices are not dividend-adjusted.
- No missing observations are included.
- Do not interpret the dates as verified trading days.
