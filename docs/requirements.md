
# Software Requirements

## Required Software

- R
- RStudio (recommended)

## R Packages

The following packages will be used as
the project develops:

- quantmod
- PerformanceAnalytics
- ggplot2
- shiny

## Installation

Install the packages in R:

```r
install.packages(c(
  "quantmod",
  "PerformanceAnalytics",
  "ggplot2",
  "shiny"
))
```

## Current Examples

The basic returns, portfolio risk,
and CAPM scripts use base R.

## Reproducibility

- Use the supplied synthetic datasets.
- Record package versions for analyses
  that require external packages.
- State all model assumptions.
- Avoid hard-coded local file paths.
- Report any missing observations.
